# Provenance, attribution and rights

The plane sampler is an extraction from the AutoAtlas research implementation.
The sequence module extracts the original plane-normal helpers and sequence
decoder. Numerical function bodies are preserved; package imports, examples
and this documentation are portable adaptations. Internal provenance records
bind the exact source and extraction; private research history and internal
coordination records are not part of this repository.

The image is the specifically authorized last-three-section crop of a
historical montage. Its annotations and pixels are retained. No other real
subject images, atlas volumes, annotations, or model weights are distributed.

Yanbo Jiang led research design and AI-assisted implementation supervision.
The code is AI-assisted; no unsupported hand-coding percentage or sole-author
claim is made. The package extraction does not re-run the scientific studies.

## Dependencies

- NumPy — array operations; BSD 3-Clause license.
- PyTorch — tensor operations and grid_sample; BSD-style license.

Dependencies are installed separately and are not vendored here. Consult the
exact installed versions' upstream licenses. Python's standard-library modules
are used for the demonstration and tests.
